# Problem DNA

> Planned data structure. Not implemented yet.

## What is Problem DNA?

Problem DNA is Aikyra's structured profile of a societal challenge — generated by AI, confirmed by humans. It turns a free-text complaint into machine-usable understanding that powers validation and matching.

## Fields

| Field | Description |
|-------|-------------|
| `problem_summary` | Concise 2–3 sentence summary of the challenge |
| `domain` | Primary sector (e.g., water, health, education, agriculture) |
| `subdomain` | Finer category within the domain |
| `affected_population` | Who is affected and approximate scale |
| `location` | Geographic area (village/city/district, coordinates later) |
| `severity` | How serious the impact is (scale, e.g., low/medium/high/critical) |
| `urgency` | Time sensitivity of intervention |
| `required_expertise` | Skills/disciplines needed to solve it |
| `required_technologies` | Technologies relevant to a solution |
| `potential_impact` | Expected outcome if solved |
| `related_challenges` | Links to similar challenges on the platform |
| `suggested_sdgs` | Relevant UN Sustainable Development Goals |
| `confidence_score` | AI's confidence in this analysis (0–1) |

## Lifecycle Statuses

```
generated → pending_validation → validated
                        │
                        └──▶ needs_review (AI output failed checks)
```

## Rules

1. Every field stores the **model + prompt version** used to generate it.
2. `confidence_score` is displayed in the UI; low-confidence fields are visually flagged.
3. Humans can edit any field; edits are recorded and mark the DNA as human-reviewed.
4. Problem DNA is advisory input for matching and validation — never an automatic decision.
